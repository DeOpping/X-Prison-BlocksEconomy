# BlocksEconomy Addon
This is an addon for [X-Prison](https://github.com/Drawethree/X-Prison) that allows you to utilize the player's blocks mined as a currency!

## Installation
1. Download the latest jar from the [releases](https://github.com/DeOpping/X-Prison-BlocksEconomy/releases)!
2. Place the jar into `plugins/X-Prison/addons`
3. Start (or restart) your server
4. Configure in `plugins/X-Prison/addon-data/BlocksEconomy/config.json`

## Usage
For any currency option in any X-Prison configuration file... set it to `blocks`<br>
Nothing happens if you try to add, set, or remove from this currency.<br>
But, any currency checks should actually work, checking the balance of the player's blocks mined.
